# Four pillars

IAClé is PistisAI renamed for the Québec market. Same codebase, same product. The name, colors, and hosts that people see come from `brand/iacle/brand.yaml`. The pillar structure is the product's, recorded in `assets/brand/brand-framework.md`.

There are four pillars. The person using the product is the center they serve, not a fifth pillar.

| Pillar | Role |
| --- | --- |
| Aiman | Face. Avatar, voice, and welcome. Show the real state. |
| Aigent | Engine. Desktop control, vision, search, files. Verify before claiming. |
| Aimotions | Heart. Personality and how the agent carries a correction. |
| Aidration | Flow. Connection, setup, and orchestration. Surface the real structure. |

When a pillar feature changes, check it against that role. A face that hides uncertainty, an engine that emits unchecked text, a heart that performs having learned, or a flow that invents a tidy story over a messy fact each miss the pillar.

If this note and `assets/brand/brand-framework.md` disagree, the brand file wins. If user-facing copy and `brand/iacle/brand.yaml` disagree, the brand file wins.
